# Coleccion test_imagenes

Cada carpeta corresponde a una entidad/ciclo de `outputs/muestra_10_corridas_aleatorias.json`.

Archivos esperados por carpeta:

- `prompt.md`: prompt exacto usado para imagen.
- `chatgpt.png`: imagen producida por ChatGPT, si estuvo disponible.
- `gemini.png`: imagen producida por Gemini, si estuvo disponible.
- `grok.png`: imagen producida por Grok, si estuvo disponible.
- `notas.md`: estado de disponibilidad o bloqueo por plataforma.
